# 📊 Consumer Sales & Sector Insights Analysis

An Exploratory Data Analysis (EDA) project focusing on consumer demographics, sector-wise order volumes, and regional sales distribution.

---

## 🚀 Key Features & Workflow
- **Data Cleaning & Preprocessing:** Handling null values, dropping unused columns, and standardizing categorical fields (`Marital_Status`, `Sector`).
- **Demographic Analysis:** Age group vs. Gender order trends.
- **Sector & Regional Insights:** Grouped aggregations and visualizations across geographic zones and top-performing Indian states.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

---

## 📈 Key Insights
1. **Target Demographics:** The **26–35** age group drives the highest purchasing volume, with female buyers making up the majority.
2. **Top Geographies:** The **Western** and **Southern** zones contribute significantly to the total revenue, with **Maharashtra** and **Uttar Pradesh** leading top-state sales.
